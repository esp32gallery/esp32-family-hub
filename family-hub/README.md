# 家庭小站

微雪 ESP32-S3-Touch-AMOLED-2.16，480×480。当前入口是「摇骰子」「说说话」，使用浅底、大图标、大触摸区，中文与数字均使用原生 32/40 像素简体中文 Medium 字形。

## 小孩怎么用

- 点「摇骰子」后，点屏幕或摇一摇：抛起、翻面、落定，带轻微音效。动画约 1 秒，静止画面为原生 480×480。启动时后台准备缓存；准备完成后才接受投骰，避免点击时现场渲染卡住。
- 点「说说话」直接进家庭对话，不选择爸爸妈妈。按住大区域说话，整屏显示说话状态；松开约 220 毫秒后发送，最长 15 秒。成功显示对勾，回到原屏。
- 有家人来信时，空闲约 5 秒内自动进入播放；播完上方可重听，下方可按住回复。爸爸和妈妈的消息进入同一个家庭会话，宝宝发出的语音统一发送给家人。
- 设置里调亮度、音量和配网；设置保存在 NVS。

## 锁屏和实体键

以**背面元件朝向自己、USB-C 接口在下方**为准，顶部从左到右是 **GPIO18 → PWR → BOOT**。位置已对照[微雪官方板载资源图](https://docs.waveshare.net/ESP32-S3-Touch-AMOLED-2.16/#板载资源)。

- 左边 GPIO18：任意页面按一下熄屏；松开后再次按它或 BOOT 唤醒。没有释放前不会立即反弹点亮。
- 中间 PWR：硬件电源键，交给电源管理芯片处理，不作为应用锁屏键。
- 右边 BOOT：亮屏时双击回首页；锁屏时按一下唤醒。
- 锁屏仍查询来信，新来信会唤醒并播放。录音和播放期间函数同步执行，硬件按键的响应会等当前动作结束；不是深度休眠。

## 手机和 Telegram

手机与 Air 在同一 Wi-Fi，用 <https://192.168.31.114:9443/> 双向语音。按住右下角麦克风，松开直接发送；家人和宝宝靠左右消息区分。普通 <http://192.168.31.114:8896/> 可查看、上传已有语音，不能直接调用手机麦克风。

第一次在 HTTP 地址下载 `/local-ca.crt` 公共根证书并安装。iPhone 还需在「设置→通用→关于本机→证书信任设置」启用信任。下载只包含公共证书，不再提供 `.p12` 私钥包。Air 必须开机，语音和索引保存在 Air 的 `~/Desktop/voice-inbox/`。

新 Bot：[family_voice_2026_bot](https://t.me/family_voice_2026_bot)。**用户必须先打开它点 Start/开始**，Bot 才能主动发送宝宝语音。2026-10-19 检查时 Telegram 返回 `chat not found`，尚未完成这一步。

Air 已配置两个权限 600 的 Token 文件，并启动独立接收服务。宝宝语音在本地保存后立即返回成功，再后台排队转 Telegram；失败每 15 秒重试。大人直接给新 Bot 发语音，接收服务保存到 Air，板子按来信流程自动播放。该流程不复用旧 Bot 的收件服务。

## 编译、烧录、预览

```sh
python3 family-hub/make_font.py
arduino-cli compile --fqbn 'esp32:esp32:esp32s3:PSRAM=opi,PartitionScheme=app3M_fat9M_16MB,CDCOnBoot=cdc,FlashSize=16M,USBMode=hwcdc,UploadSpeed=460800' family-hub
arduino-cli upload --fqbn 'esp32:esp32:esp32s3:PSRAM=opi,PartitionScheme=app3M_fat9M_16MB,CDCOnBoot=cdc,FlashSize=16M,USBMode=hwcdc,UploadSpeed=460800' -p /dev/cu.usbmodem2101 family-hub
```

原带屏板 MAC：`44:BD:8D:78:9F:B4`。不要误刷另一块 `/dev/cu.usbmodem1101`。

预览生成见 [preview/README.md](../preview/README.md)。C++ 主机和固件共用 `roll_motion.h`、`dice_sdf.h`；24 张 240×240 姿态预先缓存在 PSRAM，播放时做完整帧缩放和抛起位移，最后显示 480×480 静帧。不会裁掉位移或重复读第 0 帧。帧率仍受全屏传输耗时约 80 毫秒限制。

串口：`s` 状态/缓存/PSRAM/MAC，`r` 投骰，`v` 家庭来信，`p` 重听，`h` 首页，`g` 设置，`l` 锁屏，`f` 回读 RGB565 帧缓冲。帧缓冲证明绘制内容，不能证明物理屏无总线问题。
